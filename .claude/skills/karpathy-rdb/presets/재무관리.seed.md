# 재무관리

## entities (시드)

### account
```yaml
type: entity
name: account
display: 계정과목
domain: [재무관리]
table: account
status: draft
pattern: TR
columns:
  - { name: id,         type: bigserial,    pk: true,  nullable: false }
  - { name: code,       type: varchar(20),  nullable: false, unique: true }
  - { name: name,       type: varchar(100), nullable: false }
  - { name: type,       type: varchar(20),  nullable: false }    # asset|liability|equity|revenue|expense
  - { name: parent_id,  type: bigint,       nullable: true }
indexes:
  - { name: ix_account_code, columns: [code], unique: true }
```

### fiscal_period
```yaml
type: entity
name: fiscal_period
display: 회계기간
domain: [재무관리]
table: fiscal_period
status: draft
columns:
  - { name: id,         type: bigserial, pk: true,  nullable: false }
  - { name: year,       type: int,       nullable: false }
  - { name: month,      type: int,       nullable: false }
  - { name: closed_at,  type: timestamptz, nullable: true }
indexes:
  - { name: ux_fiscal_period_ym, columns: [year, month], unique: true }
```

### ledger_entry
```yaml
type: entity
name: ledger_entry
display: 분개
domain: [재무관리]
table: ledger_entry
status: draft
pattern: RO
columns:
  - { name: id,                type: bigserial,    pk: true,  nullable: false }
  - { name: fiscal_period_id,  type: bigint,       nullable: false }
  - { name: account_id,        type: bigint,       nullable: false }
  - { name: debit,             type: numeric(15,2), nullable: false, default: 0 }
  - { name: credit,            type: numeric(15,2), nullable: false, default: 0 }
  - { name: description,       type: varchar(255), nullable: true }
  - { name: posted_at,         type: timestamptz,  nullable: false, default: now() }
indexes:
  - { name: ix_ledger_period, columns: [fiscal_period_id] }
  - { name: ix_ledger_account, columns: [account_id] }
```

## rules (시드 비즈니스 규칙)
- (year, month) 조합은 fiscal_period에서 유일
- 분개 1행은 debit 또는 credit 중 하나만 0이 아니어야 함 (CHECK 제약 검토)
- 마감된(closed_at is not null) period에는 ledger_entry 추가 금지
