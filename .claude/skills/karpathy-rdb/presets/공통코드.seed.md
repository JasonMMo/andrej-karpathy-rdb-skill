# 공통코드

한국 기업 시스템의 사실상 표준 lookup 도메인. 모든 비즈니스 도메인이
varchar enum 컬럼(`status`, `type`, `category`, `gender`, `currency` 등)을
이 도메인의 `(group_code, code)` 쌍으로 치환하도록 설계.

## entities (시드)

### code_group
```yaml
type: entity
name: code_group
display: 코드그룹
domain: [공통코드]
table: code_group
status: draft
pattern: D2
columns:
  - { name: id,          type: bigserial,    pk: true,  nullable: false }
  - { name: code,        type: varchar(60),  nullable: false, unique: true }  # ORDER_STATUS, GENDER ...
  - { name: name,        type: varchar(100), nullable: false }
  - { name: description, type: varchar(500), nullable: true }
  - { name: is_system,   type: boolean,      nullable: false, default: false }  # boot 시 보장, UI 삭제 금지
  - { name: created_at,  type: timestamptz,  nullable: false, default: now() }
indexes:
  - { name: ix_code_group_code, columns: [code], unique: true }
```

### code
```yaml
type: entity
name: code
display: 코드
domain: [공통코드]
table: code
status: draft
pattern: MD
columns:
  - { name: id,          type: bigserial,    pk: true,  nullable: false }
  - { name: group_id,    type: bigint,       nullable: false }
  - { name: code,        type: varchar(60),  nullable: false }   # PAID / SHIPPED / MALE ...
  - { name: name,        type: varchar(100), nullable: false }
  - { name: sort_no,     type: int,          nullable: false, default: 0 }
  - { name: is_active,   type: boolean,      nullable: false, default: true }
  - { name: attribute1,  type: varchar(200), nullable: true }    # 그룹별 메타 (예: 색상 hex)
  - { name: attribute2,  type: varchar(200), nullable: true }    # 그룹별 메타 (예: 아이콘)
  - { name: attribute3,  type: varchar(200), nullable: true }
  - { name: created_at,  type: timestamptz,  nullable: false, default: now() }
  - { name: updated_at,  type: timestamptz,  nullable: false, default: now() }
indexes:
  - { name: ux_code_group_code,    columns: [group_id, code], unique: true }
  - { name: ix_code_group_sort,    columns: [group_id, sort_no] }
  - { name: ix_code_group_active,  columns: [group_id, is_active] }
```

### code_history
```yaml
type: entity
name: code_history
display: 코드 변경이력
domain: [공통코드]
table: code_history
status: draft
pattern: RO
columns:
  - { name: id,            type: bigserial,    pk: true,  nullable: false }
  - { name: code_id,       type: bigint,       nullable: false }
  - { name: change_type,   type: varchar(20),  nullable: false }   # CREATE / UPDATE / DEACTIVATE
  - { name: old_name,      type: varchar(100), nullable: true }
  - { name: new_name,      type: varchar(100), nullable: true }
  - { name: old_is_active, type: boolean,      nullable: true }
  - { name: new_is_active, type: boolean,      nullable: true }
  - { name: changed_by,    type: bigint,       nullable: true }    # app_user.id (권한관리 도메인 참조)
  - { name: changed_at,    type: timestamptz,  nullable: false, default: now() }
  - { name: reason,        type: varchar(500), nullable: true }
indexes:
  - { name: ix_code_history_code,       columns: [code_id] }
  - { name: ix_code_history_changed_at, columns: [changed_at] }
```

## rules (시드 비즈니스 규칙)
- `code_group.code` 는 시스템 전역 유일. 컨벤션: 대문자 + underscore (`ORDER_STATUS`, `PAYMENT_METHOD`)
- `(group_id, code)` 는 composite unique — 한 그룹 내 코드값 중복 금지
- `is_system=true` 그룹/코드는 application boot 시 보장되어야 하며 UI 에서 삭제/비활성화 불가
- 코드 수정/비활성화는 hard delete 금지 — `is_active=false` 로 soft delete, 이력은 `code_history` 에 RO 로 적재
- `attribute1..attribute3` 의 의미는 그룹별로 다름 — `code_group.description` 에 메타 컨벤션 명시
- 다른 도메인의 enum 성격 varchar 컬럼 (`status`, `type`, `category` 등) 은 `code.code` 를 참조하는 논리 FK 로 운용. 물리 FK 강제 여부는 응용 정책 (대량 데이터 성능 trade-off)
- 코드 조회는 캐싱 전제 — 그룹 단위로 application boot 시 또는 첫 조회 후 메모리 캐시. 변경 시 cache invalidation 신호 발행
- `code.sort_no` 는 UI dropdown 정렬용. 동일 sort_no 는 `code` 알파벳 순 tiebreak
